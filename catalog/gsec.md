# 📗 GSEC — GIAC Security Essentials

[🏠 Profile](https://github.com/RochaCrypt) · [📚 Catalog](../README.md) · <img src="https://img.shields.io/badge/🔵_Defensive-0d1117?style=flat-square&labelColor=0d1117" alt="defensive"/>

> GIAC / SANS (SEC401) · broad, hands-on security fundamentals.

## 🔎 What it is

A respected foundational GIAC certification proving practical, working knowledge across the breadth of information security — deeper and more hands-on than typical entry exams.

## 🎯 What it validates

- Networking and protocol security
- Cryptography and access control
- Defensive tools and hardening
- Incident handling basics

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **Defence in depth** | Layered controls so no single failure is fatal |
| **Hardening** | Reducing a system's attack surface |
| **Cryptography** | Protecting data confidentiality and integrity |
| **Access control** | Deciding who may reach which resources |
| **Logging** | Recording events for detection and investigation |
