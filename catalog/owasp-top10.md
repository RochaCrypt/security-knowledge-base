# 🕸️ OWASP Top 10

[🏠 Profile](https://github.com/RochaCrypt) · [📚 Catalog](../README.md) · <img src="https://img.shields.io/badge/🧭_Framework-0d1117?style=flat-square&labelColor=0d1117" alt="framework"/>

> The most widely used awareness list for web application risks.

## 🔎 What it is

A free, community-driven list of the most critical web application security risks, updated periodically. The de-facto starting point for web app security testing and secure development.

## 🎯 What it validates

- Ranks the most critical web app risks
- Guides secure coding and testing priorities
- Provides a shared language for findings
- Underpins many pentest methodologies

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **Broken Access Control** | Users acting outside their intended permissions |
| **Injection** | Untrusted input changing a query or command (e.g. SQLi) |
| **Cryptographic Failures** | Weak or missing protection of sensitive data |
| **SSRF** | Server-Side Request Forgery — forcing the server to make requests |
| **Security Misconfiguration** | Insecure defaults, verbose errors, open settings |
