# 📊 CISM — Certified Information Security Manager

[🏠 Profile](https://github.com/RochaCrypt) · [📚 Catalog](../README.md) · <img src="https://img.shields.io/badge/📊_Grc-0d1117?style=flat-square&labelColor=0d1117" alt="grc"/>

> ISACA · running a security programme, not individual controls.

## 🔎 What it is

ISACA's certification for security managers. Focuses on governance, risk, programme development and incident management — leadership and strategy rather than hands-on configuration.

## 🎯 What it validates

- Information security governance
- Risk management
- Building and running a security programme
- Incident management

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **Governance** | Aligning security strategy with business objectives |
| **Risk appetite** | How much risk an organisation is willing to accept |
| **Security metrics** | Measurable indicators of programme performance |
| **Maturity model** | A way to rate how developed a capability is |
| **Business alignment** | Ensuring security supports, not blocks, the business |
