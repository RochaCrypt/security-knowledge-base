## 🔎 What it is

A vendor certification proving you can deploy, configure and operate the CrowdStrike Falcon endpoint platform — policies, host management and Real Time Response.

## 🎯 What it validates

- Sensor deployment and update policies
- Host groups and policy precedence
- Prevention, detection and response policies
- Custom IOAs, exclusions and RTR

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **EDR** | Endpoint Detection and Response — records and blocks endpoint activity |
| **Host group** | A set of endpoints that policies are applied to |
| **Policy precedence** | Which policy wins when a host is in several groups |
| **RTR** | Real Time Response — remote shell for triage and containment |
| **IOA** | Indicator of Attack — behaviour-based detection logic |
