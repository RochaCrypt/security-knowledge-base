# 🏛️ CISSP — Certified Information Systems Security Professional

[🏠 Profile](https://github.com/RochaCrypt) · [📚 Catalog](../README.md) · <img src="https://img.shields.io/badge/📊_Grc-0d1117?style=flat-square&labelColor=0d1117" alt="grc"/>

> ISC2 · the senior, management-level security certification.

## 🔎 What it is

A broad, management-oriented certification across eight domains, widely seen as a benchmark for senior security roles. Requires five years of relevant paid experience.

## 🎯 What it validates

- Security and risk management, asset security
- Architecture, engineering and network security
- Identity and access management
- Assessment, operations and software security

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **Risk management** | Identifying, assessing and treating risk to acceptable levels |
| **Defence in depth** | Layered controls across the environment |
| **BCP/DR** | Business Continuity and Disaster Recovery planning |
| **Access control models** | DAC, MAC, RBAC, ABAC ways to grant access |
| **Due care / due diligence** | Acting responsibly and verifying that you do |
