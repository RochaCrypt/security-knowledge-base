## 🔎 What it is

Two beginner certifications that pair together: Ethical Hacking Essentials introduces offensive basics, and Network Defense Essentials introduces defensive controls. A gentle on-ramp to security.

## 🎯 What it validates

- Hacking fundamentals and threat types (EHE)
- Password, web and network attack basics (EHE)
- Network security controls and access control (NDE)
- Cryptography, data security and monitoring (NDE)

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **Attack surface** | All the points where an attacker could try to get in |
| **Access control** | Deciding who may reach which resources |
| **Administrative control** | Policies and procedures (vs technical/physical controls) |
| **PKI** | Public Key Infrastructure managing digital certificates |
| **Hardening** | Reducing a system's attack surface by removing weaknesses |
