# 🟦 SC-200 — Microsoft Security Operations Analyst

[🏠 Profile](https://github.com/RochaCrypt) · [📚 Catalog](../README.md) · <img src="https://img.shields.io/badge/🔵_Defensive-0d1117?style=flat-square&labelColor=0d1117" alt="defensive"/>

> Microsoft · running detection and response with Defender and Sentinel.

## 🔎 What it is

Microsoft's SOC-focused certification. Proves you can detect, investigate and respond to threats using Microsoft Defender and Sentinel, including writing queries to hunt in data.

## 🎯 What it validates

- Threat detection with Microsoft Defender
- Investigation and response
- Threat hunting with KQL
- Managing Sentinel (SIEM/SOAR)

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **KQL** | Kusto Query Language for searching Sentinel/Defender data |
| **SOAR** | Security Orchestration, Automation and Response |
| **Playbook** | Automated response workflow |
| **Analytics rule** | Logic that generates an alert from data |
| **Incident** | A grouped set of related alerts to investigate |
