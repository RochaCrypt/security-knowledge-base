[🏠 Profile](https://github.com/RochaCrypt) · [📚 Catalog](../README.md) · <img src="https://img.shields.io/badge/🔴_Offensive-0d1117?style=flat-square&labelColor=0d1117" alt="offensive"/>

> PortSwigger · hands-on web security from the makers of Burp Suite.

## 🔎 What it is

A practical web security certification from PortSwigger, tied to the free Web Security Academy. The exam has you exploit deliberately vulnerable apps to prove real skill, not memorisation.

## 🎯 What it validates

- Exploiting a wide range of web vulnerabilities
- Using Burp Suite effectively
- Chaining bugs to reach admin/data
- Working under time pressure

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **Web Security Academy** | PortSwigger's free labs covering each vulnerability class |
| **Access control** | Ensuring users can't act beyond their permissions |
| **SSRF** | Server-Side Request Forgery |
| **Prototype pollution** | JavaScript flaw that can escalate to RCE |
| **Burp Intruder/Repeater** | Core Burp tools for testing requests |
