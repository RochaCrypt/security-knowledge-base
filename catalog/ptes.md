# 🧩 PTES — Penetration Testing Execution Standard

[🏠 Profile](https://github.com/RochaCrypt) · [📚 Catalog](../README.md) · <img src="https://img.shields.io/badge/🧭_Framework-0d1117?style=flat-square&labelColor=0d1117" alt="framework"/>

> A community standard for how a penetration test should be run.

## 🔎 What it is

A methodology that defines the phases a professional penetration test should follow, from first contact with the client to the final report. It standardises *how* testing is done, not which tools are used.

## 🎯 What it validates

- Defines 7 phases of an engagement
- Aligns testers and clients on scope and expectations
- Structures consistent, repeatable testing
- Feeds directly into report quality

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **Pre-engagement** | Agreeing scope, rules and goals before any testing |
| **Threat modeling** | Identifying likely attackers and valuable targets |
| **Exploitation** | Gaining access by leveraging vulnerabilities |
| **Post-exploitation** | Assessing real impact of the access gained |
| **Reporting** | Communicating findings and risk to the audience |
