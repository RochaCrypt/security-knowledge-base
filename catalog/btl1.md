> Security Blue Team · practical, hands-on defensive operations.

## 🔎 What it is

A fully practical blue-team certification covering the core SOC analyst skills through a hands-on exam in a realistic environment. Popular for breaking into defensive roles.

## 🎯 What it validates

- Phishing analysis
- SIEM and log investigation
- Threat intelligence
- Digital forensics and incident response

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **SOC** | Security Operations Centre — the team monitoring for threats |
| **Phishing triage** | Analysing suspicious emails for indicators and intent |
| **Threat intelligence** | Knowledge about adversaries used to inform defence |
| **DFIR** | Digital Forensics and Incident Response |
| **Log source** | A system feeding events into the SIEM |
