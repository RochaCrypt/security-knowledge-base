# 🛠️ MITRE D3FEND

[🏠 Profile](https://github.com/RochaCrypt) · [📚 Catalog](../README.md) · <img src="https://img.shields.io/badge/🧭_Framework-0d1117?style=flat-square&labelColor=0d1117" alt="framework"/>

> MITRE · a knowledge graph of defensive countermeasures.

## 🔎 What it is

A companion to ATT&CK that catalogues defensive techniques and maps them to the offensive techniques they counter — turning 'what attackers do' into 'what defenders can do about it'.

## 🎯 What it validates

- Catalogues defensive countermeasures
- Maps defences to ATT&CK techniques
- Supports control-gap analysis
- Standardises defensive vocabulary

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **Countermeasure** | A defensive technique that mitigates an attack |
| **Digital artifact** | The object a defence acts on (file, process, packet) |
| **Harden** | Reducing attack surface proactively |
| **Detect** | Identifying malicious activity |
| **Evict** | Removing an attacker from the environment |
