> CompTIA · behavioural analytics for SOC and threat detection.

## 🔎 What it is

A defensive, analyst-focused certification about detecting and responding to threats using data and behavioural analytics. Bridges Security+ and more advanced blue-team work.

## 🎯 What it validates

- Security operations and monitoring
- Vulnerability management and prioritisation
- Incident response and management
- Reporting and communication

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **SIEM** | System that aggregates and correlates security logs for detection |
| **IOC** | Indicator of Compromise — evidence a system may be breached |
| **Threat hunting** | Proactively searching for threats that evaded detection |
| **Vulnerability prioritisation** | Ranking fixes by real risk, not just CVSS |
| **Playbook** | A predefined set of response steps for an incident type |
