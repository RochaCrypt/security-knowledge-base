# 🔧 SSCP — Systems Security Certified Practitioner

[🏠 Profile](https://github.com/RochaCrypt) · [📚 Catalog](../README.md) · <img src="https://img.shields.io/badge/🔵_Defensive-0d1117?style=flat-square&labelColor=0d1117" alt="defensive"/>

> ISC2 · hands-on operational security across seven domains.

## 🔎 What it is

An ISC2 certification for hands-on security practitioners implementing and operating controls day to day. Often described as a technical, operational counterpart to the more strategic CISSP.

## 🎯 What it validates

- Access controls and operations
- Risk identification and monitoring
- Incident response and recovery
- Network, systems and cryptography basics

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **Access control model** | How permissions are granted (DAC, MAC, RBAC) |
| **Least privilege** | Only the access actually needed |
| **Monitoring** | Watching systems for anomalies |
| **Endpoint protection** | Securing individual devices |
| **Cryptography** | Protecting data at rest and in transit |
