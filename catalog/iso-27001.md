[🏠 Profile](https://github.com/RochaCrypt) · [📚 Catalog](../README.md) · <img src="https://img.shields.io/badge/🧭_Framework-0d1117?style=flat-square&labelColor=0d1117" alt="framework"/>

> The international standard for an Information Security Management System.

## 🔎 What it is

A certifiable international standard defining how to run an Information Security Management System (ISMS) — a risk-based, auditable approach to managing security across an organisation.

## 🎯 What it validates

- Defines requirements for an ISMS
- Drives risk assessment and treatment
- Provides a control catalogue (Annex A)
- Enables independent certification

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **ISMS** | The management system governing information security |
| **Annex A** | The catalogue of controls (93 in the 2022 version) |
| **Statement of Applicability** | Which controls apply and why |
| **Risk treatment** | Accept, mitigate, transfer or avoid each risk |
| **PDCA** | Plan-Do-Check-Act cycle of continual improvement |
