# 🥷 OSEP — OffSec Experienced Penetration Tester

[🏠 Profile](https://github.com/RochaCrypt) · [📚 Catalog](../README.md) · <img src="https://img.shields.io/badge/🔴_Offensive-0d1117?style=flat-square&labelColor=0d1117" alt="offensive"/>

> OffSec (PEN-300) · evasion and advanced attacks against hardened targets.

## 🔎 What it is

An advanced practical certification focused on bypassing modern defences — antivirus, application whitelisting and network filtering — and on advanced Active Directory attacks. Part of the OSCE3 group.

## 🎯 What it validates

- Antivirus and defence evasion
- Advanced Active Directory attacks
- Client-side and phishing techniques
- Custom tooling to bypass controls

## 🧠 Key concepts & definitions

| Term | Definition |
| :--- | :--- |
| **AV evasion** | Modifying payloads so endpoint protection doesn't flag them |
| **Application whitelisting** | Only approved apps run — attackers must find bypasses |
| **AMSI bypass** | Evading Windows' script-scanning interface |
| **Shellcode** | Position-independent code a payload injects and runs |
| **Lateral movement** | Spreading from one host to others in the domain |
